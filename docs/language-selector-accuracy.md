# Language Selector — Accuracy & Charts

This document explains how we measure accuracy for the Language Selector and shows example charts generated by the evaluation script.

Metrics
- Overall accuracy: fraction of messages where predicted language matches the ground-truth label.
- Per-language accuracy: accuracy computed individually for each language in the test set.
- Confusion matrix: visual matrix showing common misclassifications between languages.

How to reproduce charts
1. Prepare a test CSV with columns: `text`, `true_lang`, `predicted_lang`.
2. Run `scripts/evaluate_language_selector.py --input test.csv --outdir docs/images`.

Example charts
- Overall accuracy bar and per-language accuracy (see `docs/images/lang_selector_accuracy.svg`).
- Confusion matrix heatmap (script saves `confusion_matrix.png` alongside charts).

Interpretation
- Review per-language bars to find low-performing languages (consider more training data or specialized preprocessing).
- Use confusion matrix to identify language pairs that are commonly mixed (e.g., `pt` vs `es`) and add targeted examples.
